СЕВЕРНЫЙ СЮРПРИЗ — НОВОГОДНИЙ МАГАЗИН
=====================================

ЧТО ИЗМЕНИЛОСЬ В ЭТОЙ ВЕРСИИ
----------------------------
1. Первый экран теперь посвящён выбору подарочной коробки.
2. Сделана карусель из пяти стилей коробок: Северное сияние, Рубиновый вечер,
   Ледяная сказка, Карамельное утро и Полночное золото.
3. Коробки можно листать стрелками, точками, нажатием на боковую карточку или
   клавишами ← и →. Карусель автоматически переключает варианты.
4. После нажатия «Выбрать эту коробку» клиент переходит к каталогу наполнения.
5. Выбранный стиль и его цена отображаются в корзине; при смене коробки итог
   автоматически пересчитывается.
6. Добавлены гирлянда с мерцающими разноцветными лампочками, крупный снег и
   ёлочные шары по бокам страницы.
7. Страница адаптируется под мобильные телефоны, планшеты и компьютеры.

КАК ЗАПУСТИТЬ
-------------
1. Распакуйте архив в отдельную папку.
2. Откройте Visual Studio Code.
3. Выберите File -> Open Folder и укажите папку newyear-gift-shop.
4. Откройте Extensions слева, найдите расширение Live Server и установите его.
5. Нажмите правой кнопкой на index.html -> Open with Live Server.

ФАЙЛЫ
-----
index.html  — структура страниц и элементы интерфейса.
styles.css  — оформление, адаптивность, гирлянда, снег и анимации.
script.js   — логика карусели, выбор коробки, каталог и корзина.

ВАЖНО
-----
Каталог, цены и коробки сейчас демонстрационные. Форма заказа пока показывает
демо-подтверждение и не отправляет заявки. Для реального магазина потребуется
подключить Telegram-бота, CRM или серверную обработку заказов.
