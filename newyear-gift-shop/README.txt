СЕВЕРНЫЙ СЮРПРИЗ — инструкция по запуску

1. Установи Visual Studio Code: https://code.visualstudio.com/
2. Распакуй архив newyear-gift-shop.zip в удобное место.
3. Открой VS Code.
4. Выбери File → Open Folder (Файл → Открыть папку) и выбери папку newyear-gift-shop.
5. В левой панели увидишь файлы:
   - index.html  — структура сайта и тексты;
   - styles.css  — цвета, оформление, адаптация под телефон;
   - script.js   — снег, переключение экранов, каталог, корзина и форма.
6. Чтобы посмотреть сайт, открой папку в Проводнике и дважды нажми index.html.
   Удобнее: в VS Code открой Extensions (иконка из четырёх квадратиков), найди
   расширение Live Server, установи его, затем нажми правой кнопкой по index.html
   и выбери “Open with Live Server”.

КАК РАБОТАЕТ ДЕМО:
- На первом экране нажми «Открыть коробку» — откроется конструктор подарка.
- Выбирай категорию или ищи товар по названию.
- Нажимай «+», чтобы добавить товар. В правой части меняется состав и цена.
- Нажми «Оформить подарок», заполни форму.
- Сейчас форма демонстрационная и никуда не отправляет заявку. Для реального магазина
  подключим Telegram-бота, CRM или backend.

КАК МЕНЯТЬ ТОВАРЫ И ЦЕНЫ:
Открой script.js и найди массив products в самом начале. Каждый объект — один товар.
Меняй name (название), price (цена в сомах), emoji (картинка-эмодзи), category и label.
Допустимые категории: sweet, cozy, beauty, decor.

КАК МЕНЯТЬ ЦЕНУ КОРОБКИ:
В начале script.js найди const BOX_PRICE = 350; и поставь свою цену.

ВАЖНО:
Цены, товары, контакты и условия доставки сейчас демонстрационные — замени их на реальные.
Сайт использует Google Fonts, поэтому для загрузки шрифтов нужен интернет. Без интернета
он всё равно откроется с запасными системными шрифтами.
